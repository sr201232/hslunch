# v1.5.0 변경 안내 — 2026-09-25

- 모든 가로 스크롤: 초당 45픽셀.
- 원산지: 나이스의 원래 식재료별 `식재료: 원산지` 표기를 유지하고, 회차당 3~5항목씩 표시합니다. 6개는 3+3, 19개는 5+5+5+4로 균등 분할하며 전체가 1~2개면 그대로 표시합니다. 다음 회차에 다음 묶음으로 넘어가고 날짜·자료 변경 시 처음부터 시작합니다.
- 국가별 묶음과 이전 15초 제한을 없앴습니다. 식재료 하나의 내용을 중간에 자르지 않으며 표시 시간은 항목 길이에 따라 달라집니다.
- 9페이지 `지성: 지극과 정성 / 상암고등학교`는 흰색입니다. 다른 긴 문장처럼 처음 1초 정지, 왼쪽으로 한 번 이동, 마지막 글자가 오른쪽 끝에 맞으면 1초 정지 후 시계로 바로 전환합니다. 짧은 문장은 가운데 2초 고정합니다. 10초 반복은 사용하지 않습니다.
- 1·3·5·7페이지 초록, 2·4·6·8페이지 노랑, 한 줄·위로 전환·시계 간격은 유지합니다.

## 급식이 없는 날

나이스가 해당 날짜에 `INFO-200`(자료 없음)을 정상 응답하면 4·6·8페이지에 `등록된 중식 정보 없음`을 표시합니다. 급식·원산지·칼로리 제목, 시계와 소개, 9페이지는 유지합니다. 이는 나이스에 등록된 중식 자료가 없다는 뜻이며, 통신 실패를 급식 없음으로 처리하지 않습니다. 통신이 실패해 당일 자료가 없으면 조회 안내를 유지하고 재시도합니다.

실제 보드 검증 결과는 `verification.md`를 참고하세요. 화면 크기는 256×32(8:1) 가정이며 실물 패널 확인과 별개입니다.
