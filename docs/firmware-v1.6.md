원산지 제목·내용 페이지를 제거해 총 7페이지입니다.

1. 현재 날짜·시간 (2초, 콜론 3회 점멸)
2. 급식정보 전광판 프로젝트 v1 by 30805김아준, GitHub @sr201232
3. 급식 정보 (1초)
4. 급식 메뉴와 알레르기 번호
5. 칼로리 정보 (1초)
6. 칼로리
7. 지성: 지극과 정성 / 상암고등학교

가로 스크롤은 45픽셀/초, 처음·끝에 1초씩 정지하고 한 번 이동합니다. 짧은 문장은 가운데에 2초 표시합니다. 1→2부터 5→6까지 위로 전환(0.4초), 6→7과 7→1은 즉시 전환합니다. 1·3·5는 초록, 2·4·6은 노랑, 마지막 7페이지는 흰색입니다.

급식 자료가 없는 날은 4·6페이지에 `등록된 중식 정보 없음`을 표시합니다. 실제 통신 실패를 급식 없음으로 표시하지 않습니다. 내부 저장 데이터 구조는 이전 버전의 캐시 호환성을 유지하지만 원산지는 화면에 사용하지 않습니다.

256×32(8:1) 기준이며 실물 패널 표시는 별도 확인이 필요합니다. GitHub README는 수정하지 않습니다.
